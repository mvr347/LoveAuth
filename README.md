# LoveAuth

Система аутентификации и авторизации для Paper сервера с хешированием Argon2, проверкой лицензии Mojang и управлением сессиями.

## Общая структура

LoveAuth предоставляет защищённую систему входа/регистрации для некрэка (offline mode) и Premium-серверов. Поддерживает криптографическую проверку лицензии через хендшейк Mojang (Yggdrasil), хранение паролей через Argon2id с pepper, шифрование данных через AES-256-GCM, управление сессиями с привязкой по IP-адресу и кулдауны на повторный вход.

## Команды

| Команда | Алиасы | Описание |
|---|---|---|
| `/loveauth` | `auth`, `авторизация`, `регистрация`, `вход` | Главная команда авторизации |
| `/ladmin` | `ладмин` | Панель администратора LoveAuth (пермишин: `loveauth.admin`) |

### Подкоманды `/loveauth`

- `register <пароль>` — зарегистрировать новый аккаунт с паролем
- `login <пароль>` — войти в аккаунт с паролем
- `logout` — выйти (завершить сессию)
- `changepassword <старый> <новый>` — изменить пароль

### Подкоманды `/ladmin`

- `reload` — перезагрузить config.yml
- `resetdb <player>` — удалить аккаунт игрока из БД
- `unblock <ip>` — разблокировать IP-адрес

## Пермишины

| Пермишин | Описание | Default |
|---|---|---|
| `loveauth.admin` | Доступ ко всем админ-командам | op |
| `loveauth.reload` | Право перезагружать конфиг | op |
| `loveauth.queue.bypass` | Пропуск очереди при входе | false |
| `loveauth.queue.priority.<число>` | Приоритет в очереди (меньше = выше) | false |

## Конфигурация (`config.yml`)

### База данных

```yaml
database:
  file: "loveauth.db"  # файл SQLite
```

### Безопасность

```yaml
security:
  # Pepper добавляется к паролю перед хешированием (генерируется автоматически)
  pepper: ""
  # AES-256-GCM ключ для шифрования чувствительных данных (генерируется автоматически)
  master-key: ""
  # Параметры Argon2id
  argon2-iterations: 10              # 10-14 рекомендуется
  argon2-memory-kb: 65536            # 64 МБ
  argon2-parallelism: 1              # 1 для большинства серверов
```

### Сессии

```yaml
session:
  enabled: true                      # включить сессии (можно заходить без пароля)
  duration-days: 7                   # длительность сессии в днях (1-28)
  bind-to-ip: true                   # сбрасывать сессию при смене IP
```

### Авторизация

```yaml
auth:
  timeout-seconds: 90                # максимум 90 секунд на вход/регистрацию
  max-attempts: 3                    # максимум неверных попыток пароля
  lockout-duration-minutes: 60       # блокировка IP на 60 минут после исчерпания попыток
  min-password-length: 6             # минимальная длина пароля
  admin-max-attempts: 5              # попытки для /ladmin
  admin-lockout-duration-minutes: 15 # блокировка admin-команд на 15 минут
  premium-skip: true                 # пропускать авторизацию для лицензионных игроков
```

### Протокольная проверка лицензии (Yggdrasil/Mojang)

```yaml
premium-verification:
  enabled: true                      # включить криптографическую проверку лицензии
  timeout-ms: 5000                   # ждать ответа 5 сек на каждом шаге хендшейка
  block-cracked-licensed-accounts: true  # блокировать крэк-вход под ником зарегистрированного лицензионника
```

## Механика входа

1. **Новый игрок** → `/loveauth register <пароль>` → создание аккаунта
2. **Лицензионный игрок** → если `premium-skip: true`, пропускается авторизация (проверяется по хендшейку Mojang)
3. **Возвращающийся игрок** → `/loveauth login <пароль>` → проверка пароля
4. **Если включены сессии** → можно заходить без пароля до истечения срока сессии (по умолчанию 7 дней)
5. **Если изменился IP** → при `bind-to-ip: true` сессия сбрасывается и требуется повторная авторизация

## Безопасность

- **Argon2id хеширование** — стойко к GPU-атакам, параметры (iterations, memory) настраиваются
- **Pepper** — секретная добавка к паролю, генерируется один раз, не меняется
- **AES-256-GCM шифрование** — для чувствительных данных в БД
- **Проверка лицензии Mojang** — криптографический хендшейк для подтверждения Premium-статуса
- **IP-привязка сессий** — защита от кражи сессии при смене IP
- **Кулдауны и блокировки** — защита от brute-force атак на пароли и admin-команды

## Структура данных

- `accounts` — аккаунты игроков (ник, хеш пароля, дата создания, последний вход)
- `sessions` — активные сессии (игрок, IP, срок действия)
- `lockouts` — временные блокировки IP (IP, дата истечения)
- `audit_log` — логи попыток входа для безопасности

## Технические детали

- Хеширование паролей: **Argon2id** (стойко к GPU-ускорению)
- Шифрование данных: **AES-256-GCM** (authenticated encryption)
- Проверка Premium: **Yggdrasil handshake** (оригинальный протокол Mojang)
- Хранилище: **SQLite** с HikariCP connection pool
